¡Aprende y Juega! 🤖

¿Cómo jugar?

1. Arrastra piezas a la mesa.
2. Toca los circulitos para conectar cables.
3. Haz clic en un cable para borrarlo.
4. Haz clic derecho en una pieza para rotarla.
5. Toca los sensores, el sol o la perilla para interactuar con ellos en vivo.

Descubre qué hace cada pieza mágica

La Pila

¡Es la comidita de los robots! Da toda la energía para que el circuito despierte.

El Panel Solar

¡Energía ecológica! Genera electricidad cuando hay sol ☀️. Toca el botón para cambiar a nublado ☁️.

Luz LED

Una lucecita mágica que brilla de colores cuando le das energía.

La Perilla (Dimmer)

¡Gírala para regular la energía! Hace que las luces brillen más suave o fuerte y los motores vayan más lento o veloz.

Sensor de Luz (LDR)

¡Detecta si es de noche! Conduce corriente cuando oscurece para encender luces automáticas.

Radar de Proximidad

¡Detecta intrusos! Pasa el ratón o un objeto cerca para activar alarmas antirrobo.

Termostato

¡Detecta el calor! Toca el termómetro: cuando hace calor 🔥 enciende el ventilador.

El Motor

¡Da vueltas y vueltas! Sirve para mover las ruedas de los autitos robot.

El Interruptor

Es como una puertita: si la cierras deja pasar la luz, ¡y si la abres se apaga!

LED RGB (Multicolor)

¡Luz de muchos colores! Haz clic sobre él para cambiar entre rosa, celeste, verde, amarillo, violeta y blanco.

Display 7 Segmentos

¡Pantalla digital! Cada vez que recibe un pulso de energía de un botón o sensor, cuenta del 0 al 9.

Sensor de Lluvia

¡Detecta agua y lluvia! Activa el botón de lluvia en el entorno para encender limpiaparabrisas o alarmas.

El Zumbador

¡Hace ruido! Como el timbre de casa o una alarma para avisarnos algo.

El Engranaje

No usa cables. ¡Ponlo cerca de un motor encendido y mira cómo gira empujado por él!
